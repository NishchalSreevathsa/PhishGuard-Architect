# User Guide: How to Load PhishGuard Architect

## Prerequisites
-   Google Chrome or Brave Browser.
-   The folder `d:\Nishchal\School of AI\Session 5\Assignment_PhishGuard` containing:
    -   `manifest.json`
    -   `popup.html`
    -   `popup.js`
    -   `styles.css`
    -   `icon.png`

## Installation Steps (Developer Mode)

1.  **Open Extensions Management**:
    -   Open Chrome.
    -   Navigate to `chrome://extensions` (type this in the address bar).
    -   Alternatively, click the 3 dots (top right) -> **Extensions** -> **Manage Extensions**.

2.  **Enable Developer Mode**:
    -   In the top right corner of the Extensions page, toggle the switch for **Developer mode** to **ON**.

3.  **Load Unpacked Extension**:
    -   A new menu bar will appear. Click the button labeled **Load unpacked**.
    -   A file picker will open. Navigate to: `d:\Nishchal\School of AI\Session 5\Assignment_PhishGuard`.
    -   **Select the Folder** (do not enter the folder, just select the root folder `Assignment_PhishGuard`).

4.  **Pin the Extension**:
    -   You should see the "PhishGuard Architect" card appear in your list.
    -   Click the **Puzzle Piece** icon 🧩 in your Chrome toolbar.
    -   Click the **Pin** icon 📌 next to PhishGuard to keep it visible.

## How to Use

1.  Click the **Shield Icon** 🛡️ in your toolbar.
2.  The popup interface will open.
3.  Enter a URL to analyze (or use the default one).
4.  Click **ANALYZE THREAT**.
5.  Watch the **Planner**, **Reasoning**, and **Actions** unfold in real-time.
